# Security

## Reporting a problem

Please do not publish sensitive information in a public issue.

For a security problem involving Gatito Dtb Pacher, open a private security report through GitHub if private reporting is available for the repository. Otherwise contact the maintainer privately before publishing details.

## DTB safety

Gatito Dtb Pacher is intended to preserve the original donor and receptor files. Generated DTBs should always be treated as test artifacts until validated on the intended hardware.

A malformed or incompatible DTB can prevent a device from booting or can affect hardware configuration. Always keep a known-good DTB backup.

Do not upload private firmware, serial numbers, credentials, or other sensitive data to issues or pull requests.
